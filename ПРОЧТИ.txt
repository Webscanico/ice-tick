Версия сайта ICE-TICK для GitHub Pages.

Отличия от версии для Beget:
- нет send.php, config.php и .htaccess (на GitHub они не работают);
- форма заявки открывает письмо на order@ice-tick.com в почте посетителя;
- в политике конфиденциальности убрано упоминание хостинга Beget;
- старый адрес /app перекидывает на /pult простой страницей.

Как выложить: загрузить ВСЁ содержимое этой папки (вместе со скрытым файлом .nojekyll)
в корень репозитория, затем Settings → Pages → Branch: main, папка / (root).
Свой домен (ice-tick.com) подключается там же, после смены DNS.
